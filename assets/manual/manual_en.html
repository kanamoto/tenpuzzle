How to Play

Ten Puzzle is a game where you must use four single-digit numbers and basic arithmetic operations to make exactly 10.
Example: **2,4,7,8 → 2 × (8 - 7 + 4)**

Four random numbers are given in each puzzle. Every puzzle has at least one solution.
Arrange the numbers and symbols to form a valid equation that equals 10.
Numbers and symbols must be placed in order from left to right.
If your equation equals 10, you solve the puzzle!

These panels represent single-digit numbers from 0 to 9.

Closing Parenthesis

Trash Can

Drag a symbol here to delete it.

Menu

Opens the game menu.

Elapsed Time

Shows how much time has passed since you started the puzzle.

Equation Display

Displays the equation you created with numbers and symbols.
If the equation is incorrect, the answer will show as "?".

Menu Options

New Question: Start a new puzzle.
Record: View past game records.
Save: Save your progress and continue later.
Manual: Open this instruction manual.

Winning the Puzzle

Create an equation that equals 10 to solve the puzzle!

Next: Try the next puzzle.

End: Exit the current session. You can start a new puzzle anytime from the menu.

Enjoy the game!
